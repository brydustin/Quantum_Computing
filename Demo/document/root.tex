\author{Dustin Bryant}

\begin{abstract}
This document is generated by Isabelle from the theory \texttt{HHL\_Demo} of the session
\texttt{Vern\_Paulsen\_QC\_Demo}.  It executes the verified HHL circuit of Part~VI on
$A=\begin{pmatrix}2&1\\1&2\end{pmatrix}$, $b=\ket0$ with three clock qubits, and proves that
every computed state is the state of the trajectory theorem.  Exact arithmetic in
$\mathbb Q(\sqrt2)$ comes from the AFP entry \emph{Implementing field extensions of the form
$\mathbb Q[\sqrt b]$}; the session is kept apart from the main document because that entry
replaces the code setup of the reals.  Proofs are folded.
\end{abstract}
