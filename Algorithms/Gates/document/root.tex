\title{HHL in Elementary Gates\\[0.5em]
  \large the black boxes compiled, and a counted instance}
\author{Dustin Bryant}
\maketitle

\begin{abstract}
This document is generated by Isabelle from the session \texttt{HHL\_Algorithm\_Gates}.  It
compiles the black boxes of the session \texttt{HHL\_Algorithm} into one- and two-qubit gates on
adjacent wires.  A reversible comparator on clean ancillas gives the sparse Hamiltonian simulation
from colour, entry and diagonal oracles; state preparation is built from an angle oracle and,
without any oracle, for a sparse right-hand side.  For the shifted cycle Laplacian $L+\mu I$ the
whole algorithm runs on elementary gates alone: phase estimation calls a controlled Trotter step,
the output is the HHL output for the Trotter product, and the number of gates is bounded
explicitly.  Proofs are folded.
\end{abstract}
